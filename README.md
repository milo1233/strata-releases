# Strata

**프로젝트 문서를 위키로 정리해 두고, 채팅으로 프로젝트 일을 맡기는 데스크톱 에이전트입니다.**

질문하면 내가 넣은 문서를 근거로 출처를 붙여 답합니다.
일을 시키면 필요한 도구를 골라 처리합니다. 도구로는 위키와 스킬(자주 하는 일의 순서를 적어 둔 것), 연결해 둔 외부 서비스의 기능을 씁니다.
문서와 위키는 프로젝트 폴더에, 대화는 내 컴퓨터의 앱 데이터 폴더에 파일로 남습니다.

### [⬇ 최신 버전 내려받기](https://github.com/milo1233/strata-releases/releases/latest) · [📘 사용 가이드 (PDF)](https://github.com/milo1233/strata-releases/releases/latest/download/Strata-User-Guide.pdf)

macOS(Apple Silicon)용 `.dmg`, Windows(64비트)용 `.exe` 를 받습니다.

---

## 무엇을 해결하려고 만들었나

프로젝트를 맡으면 기획서·회의록·보고서가 폴더와 메일, 지라, 컨플루언스, Figma 에 나뉘어 쌓입니다.
필요한 내용을 찾으려면 여러 곳을 열어 봐야 합니다. 일반 챗봇에 물으면 그 답이 어디서 나왔는지 확인하기 어렵습니다.
찾은 내용을 지라 이슈나 문서로 옮기는 일도 매번 손으로 해야 합니다.

Strata 의 목표는 세 가지입니다.

1. **프로젝트 자료를 한곳에 모아 계속 보강합니다.** 문서를 넣을 때마다 주제별 위키가 갱신되고, 채팅에서 나온 결론도 위키에 더해집니다.
2. **답에는 근거를 붙입니다.** 어느 문서의 어느 대목에서 나온 말인지 그 자리에서 확인할 수 있게 합니다.
3. **찾고 정리하고 옮기는 일까지 채팅으로 맡깁니다.** 위키·스킬·외부 서비스를 골라 써서 일을 끝냅니다. 다만 파일을 저장하거나 외부로 보내기 전에는 반드시 확인을 받습니다.

## 이렇게 씁니다

채팅에 이렇게 말하면 Strata 가 다음 일을 합니다.

| 이렇게 말하면 | Strata 가 하는 일 |
|---|---|
| 「지난주 회의록 요약해서 지라 이슈로 올려 줘」 | 위키에서 회의록을 찾아 요약하고, 확인 창을 띄운 뒤 지라에 이슈를 만듭니다. |
| 「결제 화면 기획이 언제 바뀌었어?」 | 위키에서 관련 문서를 찾아 답하고, 인용한 문서와 대목을 함께 보여 줍니다. |
| 「/회의록정리」 + 회의록 파일 (직접 만들어 둔 스킬) | 그 스킬에 적어 둔 순서와 결과 모양대로 회의록을 정리합니다. |
| 「Notion 연결해 줘」 | 연결할 주소를 찾아 확인 창에 보여 주고, 확인을 받은 뒤 커넥터(외부 서비스 연결)로 넣습니다. |
| 일 서너 가지를 한 번에 | 할 일 목록으로 나눠 하나씩 처리하고 진행 상황을 체크리스트로 보여 줍니다. 중간에 멈추면 「이어서 해」 로 남은 일부터 합니다. |

## 주요 기능

### 채팅 에이전트
질문을 받으면 위키에서 먼저 찾아보고 출처를 붙여 답합니다.
파일·사진·링크를 채팅에 붙여 그 자료에 대해 물을 수도 있습니다.
여러 단계로 된 일은 할 일 목록으로 나눠 처리합니다.
외부 서비스의 기능을 쓰거나 파일을 저장하기 전에는 확인 창이 뜹니다. 자주 쓰는 기능은 [항상 허용] 을 누르면 다음부터 확인 창 없이 씁니다.

### 위키
한글(`.hwp`·`.hwpx`)·워드·엑셀·PDF·마크다운·텍스트 문서와 웹페이지·유튜브 링크를 넣으면 주제별 위키 문서로 정리합니다.
정해 둔 지라 이슈와 컨플루언스 페이지를 그 아래 하위 항목까지 함께 가져와 문서로 만듭니다.
문서를 더 넣으면 위키를 처음부터 다시 만들지 않고 바뀐 부분만 반영합니다.
엑셀과 한글 문서의 표는 병합된 칸 구조를 그대로 저장해, 숫자가 다른 항목에 붙지 않습니다.

### 출처 확인
답변마다 인용한 위키 문서가 표시되고, 인용한 대목을 그 자리에서 볼 수 있습니다.

### 스킬
「회의록에서 할 일만 뽑기」 처럼 자주 하는 일의 순서와 결과 모양을 스킬로 저장해 둡니다.
입력창에 `/` 를 치면 스킬 목록이 뜨고, 골라서 바로 씁니다. Strata 가 필요할 때 알아서 고르게 둘 수도 있습니다.
채팅으로 이야기를 나누며 새 스킬을 만들 수 있고, Claude Code 형식의 스킬 파일을 그대로 넣어도 됩니다.

### 지시 파일
「디자인 질문은 `/figma-review` 스킬을 먼저 써라」 처럼 이 프로젝트에서 스킬과 커넥터를 어떻게 쓸지 `AGENTS.md` 에 적어 둡니다.
Strata 는 질문할 때마다 `AGENTS.md` 를 함께 언어모델에 보냅니다. `guidelines/` 폴더의 지침 문서는 목록만 보내고, 언어모델이 그중 질문과 관련 있는 문서만 골라 읽습니다.
지시 파일은 프로젝트 폴더 안에 있으므로, 폴더를 함께 쓰는 사람은 모두 같은 지시 파일을 씁니다.

### 커넥터 (외부 서비스 연결)
지라·컨플루언스(Atlassian), Notion, Sentry, Miro 같은 서비스의 MCP 서버를 연결해 그 서비스의 기능을 채팅에서 씁니다.
MCP 서버는 외부 서비스가 자기 기능을 언어모델이 쓸 수 있게 열어 둔 서버입니다.
추천 목록에서 고르거나, 채팅으로 연결해 달라고 하거나, 주소를 직접 넣어 연결합니다.
로그인은 브라우저에서 하고, 로그인 정보는 이 컴퓨터의 암호화 저장소에만 둡니다.

### Figma 변경 정리
Figma 파일을 등록하고 기간을 고르면 두 시점 사이에 달라진 점을 화면마다 카드 한 장으로 정리합니다.
근거가 된 영역과 그림을 함께 보여 주고, 그 카드를 지라 이슈로 바로 올릴 수 있습니다.

### 여럿이 함께 쓰기
프로젝트 폴더를 공유 드라이브에 두고, 각자 자기 컴퓨터의 Strata 에서 그 폴더를 등록해 함께 씁니다.
원본 문서·위키·지시 파일·프로젝트 스킬은 함께 보고, 대화와 사용자 메모리(답변 말투나 길이처럼 내가 정해 둔 취향)는 사람마다 따로 남습니다.
위키 정리는 한 번에 한 컴퓨터만 합니다. 다른 컴퓨터에서 정리하는 중이면, 이 컴퓨터의 Strata 는 그 정리가 끝날 때까지 기다렸다가 이어서 합니다.

### 언어모델 선택
Claude 계정으로 로그인해 쓸 수도 있고, Ollama Cloud 나 OpenAI 와 같은 방식으로 접속하는 모델 서버를 주소와 API 키로 연결해 쓸 수도 있습니다.
어느 것을 골라도 위키·스킬·할 일 목록·커넥터를 똑같이 씁니다.

## 데이터는 어디에 남나

Strata 가 무엇을 내 컴퓨터에 두고 무엇을 밖으로 보내는지 정리했습니다.

- 문서·위키·지시 파일은 프로젝트 폴더에 파일로 남습니다. Strata 가 외부 저장소에 따로 올리지는 않습니다.
- 대화와 사용자 메모리는 내 컴퓨터의 앱 데이터 폴더에 남습니다. 프로젝트 폴더를 함께 써도 다른 사람에게 보이지 않습니다.
- 질문하거나 문서를 정리할 때는 질문과 관련 내용을 고른 언어모델 서비스로 보냅니다.
- 언어모델 키와 외부 서비스 로그인 정보는 운영체제의 암호화 저장소에 둡니다.
- 프로젝트 폴더를 압축해 넘기면 받은 쪽에서 위키와 지시 파일을 그대로 엽니다. 대화는 함께 넘어가지 않습니다.

## 설치와 준비물

운영체제에 맞는 설치 파일을 받고, 처음 실행할 때만 아래 단계를 한 번 거칩니다.

| 환경 | 설치 파일 | 처음 실행할 때 |
|---|---|---|
| macOS (Apple Silicon) | `Strata-<버전>-arm64.dmg` | 앱을 응용 프로그램으로 옮긴 뒤 **우클릭 → 열기** 로 엽니다. |
| Windows (64비트) | `Strata-Setup-<버전>.exe` | 보안 경고가 나오면 **추가 정보 → 실행** 을 누릅니다. |

앱에 코드 서명(누가 만든 앱인지 운영체제가 확인하는 전자 서명)이 없어 처음 한 번은 운영체제가 경고를 띄웁니다. macOS 에서 「손상되었기 때문에 열 수 없습니다」 가 나올 때의 해결 방법은 사용 가이드 2장에 있습니다.
새 버전이 올라오면 앱을 켤 때 안내 창이 뜹니다.

앱 계정은 따로 없습니다. 쓰려는 기능에 따라 아래가 필요합니다.

| 준비물 | 필요한 때 |
|---|---|
| Claude 계정, 또는 Ollama Cloud · OpenAI 호환 서버의 키 | 항상 (문서 정리와 질문) |
| 아틀라시안 API 토큰 | 지라·컨플루언스 내용을 위키로 가져올 때 |
| Figma 개인 액세스 토큰 | Figma 변경을 정리할 때 |

토큰은 각 서비스에서 직접 만드는 접속용 문자열입니다. 앱 설정의 [토큰 발급 페이지 열기] 로 만드는 곳에 바로 갑니다.

언어모델 사용료는 준비한 계정이나 키에 청구됩니다.
